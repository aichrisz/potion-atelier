# Changelog

## 1.0.0 — 2026-10-22

### Added
- A playable180-active-second cozy potion-shop shift with six original fictional recipes.
- Three real brewing stages: ingredient selection, fire-driven temperature and timed stirring, followed by bottling and serving.
- Quality-based virtual payment and reputation, three initial recipes and one unlock per completed shift until all six.
- Safe local completed-shift progress, recipe ledger, result summary and repeatable next shifts.
- Original warm shop illustrations, responsive native controls, keyboard/touch support, explicit resume and reduced decorative motion.
- A self-contained offline HTML export, seven-file static build and complete reproducible source ZIP.

### Reliability
- Once-only serving/finish transactions, strict numeric bounds, detached snapshots and no runtime network dependencies.
- Independent domain/property, native browser, offline/build, accessibility, storage and responsive checks. See `docs/tdd-evidence.md` for real outcomes and audit-freshness limits.
- Local tooling refuses private paths and symlinked serving/output paths. No public deployment is included in this local release.
